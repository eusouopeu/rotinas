# Migração React/Vite — estado e limites

`webapp/` é uma reescrita incremental; legado na raiz ainda é produção e os comandos APK/Electron o empacotam. Não tente concluir a migração numa tarefa. O corte só ocorre quando telas, lógica e pontes nativas tiverem paridade.

Vite usa `root:"webapp"`, `base:"./"`, saída `webapp-dist`; TypeScript é estrito. Scripts: `dev:react`, `build:react`, `test:react`, `typecheck:react`. Estado: store Zustand e storage compatível com os mesmos formatos/dados legados. O CSS é o `app.css` raiz importado por `main.tsx`; não há Tailwind/CSS Modules. Preserve `#app`.

Portados parcialmente: Home (incluindo agenda inline "Semana"), Settings (incluindo Backup, Calendário externo, Mini player, Sincronização com nuvem e Integrações MCP), RoutineEditor/Detail, Player/Done, Metas, Notes/NoteEditor, pastas/documentos de modelo (scoreboard, thoughtrecord, proscons, mercado, matriz 2×2, kanban, viagem) e Despesas (`ExpenseFolder.tsx` — tela dedicada fora do molde genérico de doc, cada lançamento é a própria "nota"). Gamificação/scoring/metas têm lógica real e testes, incluindo a simulação "e se" da pontuação (prévia dentro do card "Pontuação do boletim" em Settings). Drag-and-drop está consolidado em `lib/dnd.ts` (`useDragReorder` + `computeStepDragTarget`/`computeKanbanDragTarget`), usado em RoutineEditor (etapas) e KanbanDoc (cartões, com os botões `‹ ›` como fallback). `templates` é passthrough genérico para não destruir documentos não tipados.

**Excluídos por decisão explícita (não portar):** PIN de bloqueio e atalhos de teclado globais. Editor Markdown live (`renderLiveEditor`/`liveAplicar`/`liveColocarCursor`, index.html:9849-10450+) também fica fora — decisão de 30/08/2026: o subsistema é grande demais (contenteditable com tradução manual de cursor DOM↔texto, interceptação de Enter/Backspace, toolbar flutuante, toggles, undo banner, cuidados de IME/mobile) pra portar nesta fase. `NoteEditor.tsx` continua com textarea simples permanentemente — não é mais um risco pendente, é decisão tomada. O legado continua com o editor live intacto; nada muda lá. Não recriar nenhum desses três itens sem novo pedido explícito.

**Diário não é mais uma tela/aba** (o legado removeu a aba Diário em 23/08/2026, commit `c627f33` — rotas, tabbar, atalho de tela e busca global saíram de lá; a agenda semana/dia da aba Rotinas cobre o uso). Uma sessão anterior do React portou `screens/Diario.tsx` como tela própria por engano, sem notar a remoção; foi removida em 30/08/2026. `lib/diario.ts` (chave/rótulo por período) continua no código — lógica pura correta, hoje sem consumidor no React (o legado ainda usa o formato para o próprio Diário/K_DIARIO). `DiarioMap`/`K_DIARIO` seguem no store e no backup pela mesma razão. Não recriar uma tela/aba "Diário" separada.
